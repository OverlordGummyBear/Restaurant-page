# Restaurant page - Nova Circuit
A fictional futuristic restaurant page built with vanilla HTML, CSS, and JavaScript, bundled with Webpack and structured around reusable page modules.

## Features
- Multi-page layout (Home, Menu, About) rendered dynamically via JavaScript

## Live Demo
Live Demo: https://overlordgummybear.github.io/Restaurant-page/

## Getting Started
Clone the repo and install dependencies.
```bash
git clone https://github.com/OverlordGummyBear/Restaurant-page.git
cd Restaurant-page
npm install
```
Then start the development server:
```bash
npx webpack serve
```
Open `http://localhost:8080` in your browser.
